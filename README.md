###  Projeto em destaque

#### [Marketplace de Automações](https://github.com/PedroNilton/marketplace-automacoes) — em desenvolvimento

Marketplace brasileiro que pretende conectar pessoas e empresas que desejam automatizar processos a profissionais especializados em automações e integrações.

- Frontend com **Next.js, React, TypeScript e Tailwind CSS**
- Backend com **NestJS** e API REST
- Persistência com **PostgreSQL e Prisma**
- Infraestrutura local com **Docker Compose**
- Arquitetura, regras de negócio e entregas orientadas por especificações

> O projeto está em construção. O repositório documenta o estado atual, as decisões técnicas e os próximos incrementos planejados.

### Hi, I'm Pedro Aurélio 👋

I'm a **Full Stack Developer** interested in turning real-world problems into well-structured, understandable, and maintainable applications.

I currently focus my studies and projects on **Java** and **TypeScript**, working with frontend and backend technologies, relational databases, technical documentation, and software development best practices.

###  Featured project

#### [Automation Marketplace](https://github.com/PedroNilton/marketplace-automacoes) — work in progress

A Brazilian marketplace designed to connect people and companies seeking process automation with professionals specialized in automation and integrations.

- Frontend built with **Next.js, React, TypeScript, and Tailwind CSS**
- Backend built with **NestJS** and a REST API
- Persistence with **PostgreSQL and Prisma**
- Local infrastructure with **Docker Compose**
- Specification-driven architecture, business rules, and delivery workflow

> This project is under active development. Its repository documents the current state, technical decisions, and planned increments.

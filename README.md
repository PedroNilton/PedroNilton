## Português

### Olá, eu sou Pedro Aurélio

Sou **Desenvolvedor Full Stack** e graduando em **Ciência da Computação** (5º período - UNIT), focado em construir sistemas web corporativos, APIs seguras e aplicações escaláveis.

Atualmente atuo na **DESO** com **PHP (Laravel e CakePHP), Vue.js e PostgreSQL**, além de integrar a **Residência Tecnológica (UNIT / FSPH)** desenvolvendo soluções em **Java 21, Spring Boot, React, TypeScript e Docker**.

### Projetos em Destaque

#### [HabitOS (CondoEconomy)](https://github.com/PedroNilton/condoeconomy-web) — Gestão Condominial Full Stack
Ecossistema completo conectando Síndicos, Porteiros e Moradores em tempo real.
- **Back-end ([`condoeconomy-api`](https://github.com/PedroNilton/condoeconomy-api)):** Java 21, Spring Boot 3, Spring Security (JWT + RBAC), WebSockets (STOMP) e PostgreSQL.
- **Front-end ([`condoeconomy-web`](https://github.com/PedroNilton/condoeconomy-web)):** React 18, TypeScript, Tailwind CSS (Mobile-First), controle de portaria, QR Code dinâmico e dashboard financeiro.

#### [FSPH Fleet Management](https://github.com/PedroNilton/fsph-fleet-management) — Sistema de Gestão de Frotas
Sistema desenvolvido na Residência Tecnológica para a Fundação de Saúde Parreiras Horta (FSPH).
- **Stack:** Java 21, Spring Boot, Spring Security (JWT), PostgreSQL, Flyway (Migrations) e Docker Compose.
- **Destaques:** Segurança stateless, matriz de permissões por perfil e provisionamento automático de setores.

#### [Marketplace de Automações](https://github.com/PedroNilton/marketplace-automacoes) — Plataforma Full Stack
Marketplace brasileiro conectando clientes a especialistas em automações e integrações.
- **Stack:** Next.js, React, NestJS, TypeScript, Prisma ORM, PostgreSQL, Docker e GitHub Actions (CI).
- **Destaques:** *Spec-Driven Development*, autenticação com Argon2id, *rate limiting* e suíte de testes (unitários, integração e E2E).

#### [AgendaLivre API](https://github.com/PedroNilton/agendalivre-api) — Agendamento Inteligente
API RESTful para gestão de horários e profissionais autônomos.
- **Stack:** Java 17, Spring Boot 3, Spring Data JPA, PostgreSQL e **Clean Architecture**.
- **Destaques:** Isolamento do domínio de negócio e validação de concorrência contra agendamentos simultâneos (*double booking*).

## English

### Hi, I'm Pedro Aurélio

I'm a **Full Stack Developer** and **Computer Science** undergraduate (5th semester - UNIT), focused on building corporate web systems, secure APIs, and scalable applications.

Currently working at **DESO** with **PHP (Laravel & CakePHP), Vue.js, and PostgreSQL**, and participating in the **UNIT / FSPH Tech Residency** building solutions with **Java 21, Spring Boot, React, TypeScript, and Docker**.

### Featured Projects

#### [HabitOS (CondoEconomy)](https://github.com/PedroNilton/condoeconomy-web) — Full Stack Condominium Management
Full-stack ecosystem connecting Property Managers, Concierges, and Residents in real time.
- **Back-end ([`condoeconomy-api`](https://github.com/PedroNilton/condoeconomy-api)):** Java 21, Spring Boot 3, Spring Security (JWT + RBAC), WebSockets (STOMP), and PostgreSQL.
- **Front-end ([`condoeconomy-web`](https://github.com/PedroNilton/condoeconomy-web)):** React 18, TypeScript, Tailwind CSS (Mobile-First), concierge parcel/visitor control, dynamic QR Code, and financial dashboard.

#### [FSPH Fleet Management](https://github.com/PedroNilton/fsph-fleet-management) — Fleet Management System
Developed during the Tech Residency for Fundação de Saúde Parreiras Horta (FSPH).
- **Stack:** Java 21, Spring Boot, Spring Security (JWT), PostgreSQL, Flyway (Migrations), and Docker Compose.
- **Highlights:** Stateless security, role-based permission matrix, and automated sector provisioning.

#### [Automation Marketplace](https://github.com/PedroNilton/marketplace-automacoes) — Full Stack Platform
Brazilian marketplace connecting clients with automation and integration specialists.
- **Stack:** Next.js, React, NestJS, TypeScript, Prisma ORM, PostgreSQL, Docker, and GitHub Actions (CI).
- **Highlights:** Spec-Driven Development, Argon2id authentication, rate limiting, and automated test suite (unit, integration, and E2E).

#### [AgendaLivre API](https://github.com/PedroNilton/agendalivre-api) — Smart Scheduling System
RESTful API for smart scheduling and independent professionals.
- **Stack:** Java 17, Spring Boot 3, Spring Data JPA, PostgreSQL, and **Clean Architecture**.
- **Highlights:** Strict domain isolation and concurrency validation to prevent double booking.
